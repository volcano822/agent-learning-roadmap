# 06 - 开源项目

> 值得学习的 Agent 开源项目，按方向分类。学习方法：先看 README 和架构图，再读核心文件，不要试图通读全部源码。

## 代码 Agent

### ⭐ OpenDevin
- **GitHub**：https://github.com/OpenDevin/OpenDevin
- **Star**：40k+
- **简介**：开源软件工程师 Agent，能自主完成代码修改、调试、测试、执行命令
- **架构特点**：
  - 基于 Agent 沙箱环境，安全执行代码和命令
  - 支持多种 Agent 实现（CodeAct、Monologue、Plan-and-Execute）
  - 浏览器工具、文件操作工具、Bash 工具
  - 插件系统，支持自定义工具
- **学习重点**：
  - `openhands/agent/` — Agent 核心逻辑
  - `openhands/runtime/` — 沙箱运行时
  - `openhands/tools/` — 工具定义和实现
- **适合方向**：代码 Agent、Computer Use

### ⭐ SWE-agent
- **GitHub**：https://github.com/princeton-nlp/SWE-agent
- **Star**：15k+
- **作者**：普林斯顿大学 NLP 组
- **简介**：在 SWE-bench 上表现优秀的代码 Agent，代码结构清晰
- **架构特点**：
  - Agent-Computer Interface（ACI）设计，精心设计的命令行界面让 LLM 更容易操作
  - 支持多种模型（GPT-4o、Claude、DeepSeek 等）
  - 完整的评估管线
- **学习重点**：
  - `sweagent/agent/` — Agent 逻辑
  - `sweagent/harness/` — 评估框架
  - ACI 界面设计（如何让 LLM 高效使用工具）
- **适合方向**：代码 Agent、Agent 评估

## 学习开源项目的方法

### 阅读顺序建议
1. **先读 README**：了解项目目标、架构、快速开始
2. **看架构图/文档**：理解整体设计
3. **跑通示例**：先让项目跑起来，直观感受
4. **读核心文件**：
   - Agent 循环（通常在 agent.py 或类似文件）
   - 工具定义（tools/ 目录）
   - 状态/记忆管理（memory.py 或 state.py）
5. **调试跟踪**：在关键位置加断点，跟踪一次完整执行流程

### 不要做的事
- ❌ 不要试图通读所有源码（大项目几十万行，不可能也没必要）
- ❌ 不要只看不用，一定要跑起来改一改
- ❌ 不要同时研究多个项目，选 1-2 个深入
