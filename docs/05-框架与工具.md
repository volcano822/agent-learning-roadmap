# 05 - 框架与工具

> 主流 Agent 框架、开发工具、评估工具、部署工具，附官方文档链接。

## Agent 框架

### ⭐ LangGraph（重点学习）
- **官方文档**：https://langchain-ai.github.io/langgraph/
- **GitHub**：https://github.com/langchain-ai/langgraph
- **示例库**：https://github.com/langchain-ai/langgraph/tree/main/examples
- **部署指南**：https://langchain-ai.github.io/langgraph/concepts/deployment/
- **语言**：Python（主）、TypeScript、JS
- **设计理念**：基于状态机的 Agent 编排，用图（Graph）定义工作流
- **核心概念**：
  - StateGraph：状态机，定义 Agent 的状态和流转
  - Node（节点）：执行具体逻辑的函数
  - Edge（边）：节点间的连接，支持条件分支
  - Checkpointer：检查点持久化，支持中断恢复和时间旅行
  - Interrupt：人机交互节点
  - Subgraph：子图嵌套
- **适合场景**：生产级复杂 Agent 工作流、需要精确控制流程的场景
- **学习资源**：LangChain Academy（https://academy.langchain.com/）

### LangChain
- **官方文档**：https://python.langchain.com/
- **GitHub**：https://github.com/langchain-ai/langchain
- **设计理念**：LLM 应用开发的组件化框架，提供 Chain、Agent、Memory 等抽象
- **与 LangGraph 关系**：LangChain 是基础组件库，LangGraph 是更高级的 Agent 编排框架
- **注意**：新项目建议直接用 LangGraph，LangChain 的 AgentExecutor 已被 LangGraph 取代

### LlamaIndex
- **官方文档**：https://docs.llamaindex.ai/
- **GitHub**：https://github.com/run-llama/llama_index
- **设计理念**：RAG 专精框架，专注于数据连接、索引和查询
- **核心概念**：
  - 数据连接器（Connector）：连接各种数据源
  - 索引（Index）：向量索引、树索引、关键词索引等
  - 查询引擎（Query Engine）：不同的查询策略
  - Router：根据查询选择合适的索引或引擎
- **适合场景**：RAG 为主的应用，复杂知识库问答

### AutoGen
- **官方文档**：https://microsoft.github.io/autogen/
- **GitHub**：https://github.com/microsoft/autogen
- **作者**：Microsoft
- **设计理念**：基于对话的多 Agent 框架，Agent 之间通过自然语言对话协作
- **核心概念**：
  - ConversableAgent：可对话的 Agent 基类
  - AssistantAgent：AI 助手角色
  - UserProxyAgent：代表用户执行操作的代理
  - GroupChat：多 Agent 群聊管理器
- **适合场景**：多 Agent 对话协作、需要人机交互的场景

### CrewAI
- **官方文档**：https://docs.crewai.com/
- **GitHub**：https://github.com/crewAIInc/crewAI
- **设计理念**：角色化多 Agent 编排，模拟团队协作
- **核心概念**：
  - Agent：定义角色、目标、背景故事
  - Task：定义任务描述和预期输出
  - Crew：Agent + Task 的组合，按流程执行
  - Process：顺序执行 vs 层级管理
- **适合场景**：角色分工明确的多 Agent 系统，快速原型

### smolagents
- **官方文档**：https://huggingface.co/docs/smolagents/
- **GitHub**：https://github.com/huggingface/smolagents
- **作者**：Hugging Face
- **设计理念**：轻量级 Agent 库，代码简洁易读
- **核心概念**：
  - CodeAgent：用代码作为推理和行动格式
  - ReactJsonAgent：用 JSON 格式的 ReAct
  - Tool：工具基类，易于自定义
- **适合场景**：学习 Agent 实现原理、轻量级应用

### Mastra
- **官方文档**：https://mastra.ai/docs
- **GitHub**：https://github.com/mastra-ai/mastra
- **语言**：TypeScript
- **设计理念**：全栈 AI Agent 框架，包含工作流、Agent、MCP、评估等
- **适合场景**：TypeScript/JavaScript 技术栈的团队

## 评估与可观测性工具

### ⭐ LangSmith
- **官方文档**：https://docs.smith.langchain.com/
- **功能**：LLM 应用的追踪、评估、数据集管理、Prompt 管理
- **特点**：与 LangChain/LangGraph 深度集成，支持自定义评估器
- **适合**：使用 LangChain 生态的团队

### Arize Phoenix
- **官方文档**：https://docs.arize.com/phoenix
- **GitHub**：https://github.com/Arize-ai/phoenix
- **功能**：开源 LLM 可观测性工具，支持 Trace、评估、监控
- **特点**：可本地部署，开源免费，支持多种框架

### RAGAS
- **GitHub**：https://github.com/explodinggradients/ragas
- **文档**：https://docs.ragas.io/
- **功能**：RAG 自动化评估框架
- **评估指标**：忠实度（Faithfulness）、答案相关性（Answer Relevancy）、上下文相关性（Context Relevancy）、上下文召回（Context Recall）

### Langfuse
- **官网**：https://langfuse.com/
- **GitHub**：https://github.com/langfuse/langfuse
- **功能**：开源 LLM 工程平台，追踪、评估、Prompt 管理
- **特点**：开源可自托管，支持多种框架集成

### Helicone
- **官网**：https://www.helicone.ai/
- **功能**：LLM 可观测性平台，专注于日志、指标和成本追踪

## 开发工具

### LiteLLM
- **GitHub**：https://github.com/BerriAI/litellm
- **文档**：https://docs.litellm.ai/
- **功能**：统一 100+ LLM 的 API 调用接口，支持模型路由、降级、成本追踪
- **适合**：需要支持多模型、做模型路由的场景

## 框架选型建议

| 场景 | 推荐框架 | 理由 |
|------|---------|------|
| 生产级复杂 Agent | LangGraph | 状态机模型最灵活，生态最成熟 |
| RAG 为主的应用 | LlamaIndex | RAG 专精，检索策略丰富 |
| 多 Agent 对话协作 | AutoGen | 对话式设计，人机交互方便 |
| 快速原型/角色分工 | CrewAI | 简单易用，角色化抽象 |
| 学习 Agent 原理 | smolagents | 代码简洁，易于理解 |
| TypeScript 技术栈 | Mastra | TS 原生，全栈能力 |
| 低代码快速验证 | Dify / Coze | 无需写代码，快速出原型 |

> **核心建议**：深入学习 LangGraph 一个框架，其余了解设计思想即可。框架会迭代，但状态机、工具调用、记忆管理这些核心概念是通用的。
