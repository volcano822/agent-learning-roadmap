## 一、Agent 基础架构

### ⭐ ReAct: Synergizing Reasoning and Acting in Language Models
- **链接**：https://arxiv.org/abs/2210.03629
- **作者**：Yao et al., Princeton & Google
- **核心思想**：将推理（Reasoning）和行动（Acting）交替进行，每一步先思考再行动，通过观察结果指导下一步推理
- **必读理由**：Agent 领域最经典论文，几乎所有现代 Agent 框架都基于此范式
- **重点理解**：Thought / Action / Action Input / Observation 的循环结构

### Reflexion: Language Agents with Verbal Reinforcement Learning
- **链接**：https://arxiv.org/abs/2303.11366
- **核心思想**：让 Agent 通过自然语言反思自己的失败，将反思写入记忆，指导后续尝试
- **重点理解**：反馈循环在 Agent 中的作用，自我改进机制

### Plan-and-Solve Prompting: Improving Zero-Shot Chain-of-Thought Reasoning
- **链接**：https://arxiv.org/abs/2305.04091
- **核心思想**：先规划任务分解，再逐步执行，比直接 CoT 效果更好
- **重点理解**：规划先于执行的范式

### Tree of Thoughts: Deliberate Problem Solving with Large Language Models
- **链接**：https://arxiv.org/abs/2305.10601
- **核心思想**：将思维组织成树结构，支持探索多条推理路径并评估选择
- **重点理解**：搜索式推理，与线性 CoT 的区别

## 二、LLM 基础

### ⭐ Attention Is All You Need
- **链接**：https://arxiv.org/abs/1706.03762
- **核心思想**：Transformer 架构，完全基于注意力机制，摒弃 RNN
- **必读理由**：所有大模型的基础，必须理解自注意力机制
- **重点理解**：Q/K/V 的计算、多头注意力、位置编码

### Chain-of-Thought Prompting Elicits Reasoning in Large Language Models
- **链接**：https://arxiv.org/abs/2201.11903
- **核心思想**：通过让模型逐步思考来提升复杂推理能力
- **重点理解**：CoT 的触发条件和效果边界

### Controllable Neural Text Generation（博客，非论文）
- **链接**：https://lilianweng.github.io/posts/2021-01-02-controllable-text-generation/
- **作者**：Lilian Weng (OpenAI)
- **核心内容**：系统讲解采样策略（temperature/top_p/top_k）和生成控制方法
- **推荐理由**：比论文更易懂，是理解 LLM 生成机制的最佳入门

## 三、RAG 检索增强生成

### ⭐ Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks
- **链接**：https://arxiv.org/abs/2005.11401
- **作者**：Lewis et al., Facebook AI
- **核心思想**：将检索到的文档作为上下文，让 LLM 基于外部知识生成答案
- **必读理由**：RAG 的开山之作
- **重点理解**：检索器与生成器的联合训练思想（实际应用中多为分开优化）

### ⭐ Lost in the Middle: How Language Models Use Long Contexts
- **链接**：https://arxiv.org/abs/2307.03172
- **核心思想**：LLM 对长上下文中间位置的信息利用较差，相关信息放在开头或结尾效果更好
- **必读理由**：直接影响 RAG 的上下文排序策略，工程上非常实用
- **重点理解**：U 型注意力分布，对 RAG 排序的指导意义

### Precise Zero-Shot Dense Retrieval without Relevance Labels (HyDE)
- **链接**：https://arxiv.org/abs/2212.10496
- **核心思想**：先用 LLM 生成一个假设性答案，再用它去检索，比直接用查询检索效果好
- **重点理解**：查询改写的一种经典方法

### Active Retrieval Augmented Generation (FLARE)
- **链接**：https://arxiv.org/abs/2305.06983
- **核心思想**：在生成过程中主动判断何时需要检索，而不是一开始就检索
- **重点理解**：动态检索 vs 静态检索

## 四、多 Agent 协作

### AutoGen: Enabling Next-Gen LLM Applications via Multi-Agent Conversation
- **链接**：https://arxiv.org/abs/2308.08155
- **作者**：Microsoft
- **核心思想**：通过可对话的 Agent 之间的自动对话来完成复杂任务
- **重点理解**：ConversableAgent 设计、GroupChat 管理器

### MetaGPT: Meta Programming for A Multi-Agent Collaborative Framework
- **链接**：https://arxiv.org/abs/2308.00352
- **核心思想**：模拟软件公司的角色分工（产品经理/架构师/工程师），用 SOP 标准化协作流程
- **重点理解**：角色化协作、标准化流程的价值

### CAMEL: Communicative Agents for Mind Exploration
- **链接**：https://arxiv.org/abs/2303.17760
- **核心思想**：通过角色扮演和任务导向的对话范式，让多个 Agent 协作完成任务
- **重点理解**：早期多 Agent 框架的设计思路

### AgentVerse: Facilitating Multi-Agent Collaboration
- **链接**：https://arxiv.org/abs/2308.10848
- **核心思想**：多 Agent 协作环境框架，分析不同协作策略的效果
- **重点理解**：协作策略的对比分析

## 五、评估与基准

### AgentBench: Evaluating LLMs as Agents
- **链接**：https://arxiv.org/abs/2308.03688
- **核心思想**：在 8 个不同环境中评估 LLM 作为 Agent 的能力
- **重点理解**：Agent 评估的维度和方法

### RAGAS: Automated Evaluation of Retrieval Augmented Generation
- **链接**：https://arxiv.org/abs/2309.15217
- **核心思想**：无需人工标注的 RAG 自动化评估框架，评估忠实度、答案相关性、上下文相关性
- **重点理解**：无参考评估的思路，LLM-as-Judge 的应用

### SWE-bench: Can Language Models Resolve Real-World GitHub Issues?
- **链接**：https://arxiv.org/abs/2310.06770
- **核心思想**：用真实 GitHub Issue 评估代码 Agent 的能力
- **重点理解**：代码 Agent 的评估方法和当前能力边界

### WebArena: A Realistic Web Environment for Building Autonomous Agents
- **链接**：https://arxiv.org/abs/2307.13854
- **核心思想**：在真实网站环境中评估网页 Agent 的任务完成能力
- **重点理解**：浏览器 Agent 的挑战和评估方法

## 六、安全与对齐

### Not what you've signed up for: Compromising Real-World LLM-Integrated Applications with Indirect Prompt Injection
- **链接**：https://arxiv.org/abs/2302.12173
- **核心思想**：通过外部数据（网页、文档）注入恶意指令，间接攻击 LLM 应用
- **重点理解**：间接提示注入的攻击方式，RAG 系统的安全风险

### OWASP Top 10 for LLM Applications
- **链接**：https://owasp.org/www-project-top-10-for-large-language-model-applications/
- **类型**：安全标准文档（非论文）
- **核心内容**：LLM 应用的 Top 10 安全风险清单
- **重点理解**：提示注入、敏感信息泄露、供应链安全等
