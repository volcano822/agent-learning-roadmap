# 03 - 课程与教程

## 系统课程

### ⭐ 吴恩达 Agentic AI（DeepLearning.AI）
- **链接**：https://learn.deeplearning.ai/courses/agentic-ai/information
- **中文翻译**：https://github.com/datawhalechina/agentic-ai
- **作者**：Andrew Ng
- **时长**：约 4-6 小时
- **适合阶段**：第 2-3 周
- **内容**：
  - 模块1：Reflection（反思）—— AI 自我批判与迭代改进
  - 模块2：Tool Use（工具使用）—— 调用 API、搜索、代码执行
  - 模块3：Planning（规划）—— 动态任务拆解与多步执行
  - 模块4：Multi-Agent Collaboration（多 Agent 协作）
  - 模块5：综合项目——构建研究 Agent
- **特点**：用纯 Python 实现，不依赖框架，从第一性原理讲设计
- **推荐理由**：吴恩达出品，质量保证，与第2周手写练习完美互补

### ⭐ Hugging Face AI Agents Course
- **链接（中文）**：https://huggingface.co/learn/agents-course/zh-CN/unit0/introduction
- **GitHub**：https://github.com/huggingface/agents-course
- **时长**：约 8-10 小时
- **适合阶段**：第 3-5 周
- **内容**：
  - Unit 0：课程介绍与环境准备
  - Unit 1：Agent 基础——Tools/Thoughts/Action/Observation
  - Unit 2：smolagents 框架——Code Agent 与推理
  - Unit 3：LangGraph——状态机与复杂工作流
  - Unit 4：RAG 与 LlamaIndex——检索增强
  - Unit 5：多 Agent 系统——协作模式与实战
  - Unit 6：进阶主题——评估、部署、MCP
- **特点**：免费、多框架覆盖、有代码练习和测验、支持中文
- **推荐理由**：Hugging Face 官方出品，Notebook 可直接在 Colab 运行
