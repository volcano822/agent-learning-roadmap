# 01 - 8 周学习路径

> 每天 2-3 小时，周末集中做项目。每天的学习资料与 `docs/02~06` 中的资源对应。

## 整体节奏

- **工作日**：学概念 + 写小练习（每天 2-3 小时）
- **周末**：集中做项目（每天至少 4 小时）
- **项目是主线**：所有概念学习都服务于当周的项目产出
- **资料标注**：📄=论文 📚=文档 🎓=课程 📖=书籍 💻=开源项目 ✍️=博客

## 第 1 周：LLM 基础与 Prompt 工程

**目标**：理解大模型工作原理，能熟练调用 API 并写出高质量 Prompt

### 周一：Transformer 核心原理

**学习内容**：自注意力机制、位置编码、Encoder/Decoder 区别、Tokenization（BPE/SentencePiece）、上下文窗口与 KV Cache 概念

**📚 学习资料**：
- 📄 [Attention Is All You Need](https://arxiv.org/abs/1706.03762) — Transformer 原始论文，精读注意力机制部分
- 🎓 [Karpathy · Neural Networks: Zero to Hero](https://www.youtube.com/playlist?list=PLAqhIrjkxbuWI23v9cThsA9GvCAUhRvKZ) — Lecture 6（从零构建 GPT），选看
- 📖 李博杰《深入理解 AI Agent》[第1章](https://bojieli.github.io/ai-agent-book/) — Agent 基础知识
- ✍️ [Jay Alammar · The Illustrated Transformer](https://jalammar.github.io/illustrated-transformer/) — 图解 Transformer，直观易懂

### 周二：采样参数与模型选型

**学习内容**：temperature、top_p、top_k、frequency_penalty 的作用与调参直觉；主流模型对比的能力边界与价格

**📚 学习资料**：
- ✍️ [Lilian Weng · Controllable Neural Text Generation](https://lilianweng.github.io/posts/2021-01-02-controllable-text-generation/) — 系统讲解采样策略
- 📚 [OpenAI API 文档 · 参数参考](https://platform.openai.com/docs/api-reference/chat) — temperature、top_p 等参数说明
- 📚 [Artificial Analysis](https://artificialanalysis.ai/) — 主流模型的速度、价格、质量对比（第三方基准）

### 周三：Prompt Engineering（上）

**学习内容**：零样本/少样本提示、角色设定、指令结构、思维链(CoT)、自洽性(Self-Consistency)、树状思维(ToT)

**📚 学习资料**：
- 📚 [OpenAI Prompt Engineering Guide](https://platform.openai.com/docs/guides/prompt-engineering) — 官方最佳实践
- 🎓 [DeepLearning.AI · ChatGPT Prompt Engineering](https://www.deeplearning.ai/short-courses/chatgpt-prompt-engineering-for-developers/) — 吴恩达短课，约1小时
- 📄 [Chain-of-Thought Prompting](https://arxiv.org/abs/2201.11903) — CoT 原始论文
- 📄 [Tree of Thoughts](https://arxiv.org/abs/2305.10601) — ToT 论文，选读
- 📖 李博杰《深入理解 AI Agent》[第2章](https://bojieli.github.io/ai-agent-book/) — 上下文工程

### 周四：Prompt Engineering（下）

**学习内容**：结构化输出（JSON/Function Calling 格式）、Few-shot 示例设计原则、Prompt 防注入、复杂任务的 Prompt 模板工程

**📚 学习资料**：
- 📚 [Anthropic Prompt Engineering Guide](https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/overview) — 结构化输出和长上下文建议
- 💻 [dair-ai/Prompt-Engineering-Guide](https://github.com/dair-ai/Prompt-Engineering-Guide) — 最全的 Prompt 技巧合集
- ✍️ [Lilian Weng · Prompt Engineering](https://lilianweng.github.io/posts/2023-03-15-prompt-engineering/) — 系统综述

### 周五：LLM API 实战

**学习内容**：OpenAI/Anthropic/国内模型 API 调用、流式输出(SSE) 处理、多轮对话历史管理、速率限制与指数退避重试、Token 计数与成本估算

**📚 学习资料**：
- 📚 [OpenAI API 文档 · 流式输出](https://platform.openai.com/docs/api-reference/chat/streaming) — SSE 流式响应
- 💻 [OpenAI Cookbook · How to stream completions](https://github.com/openai/openai-cookbook/blob/main/examples/How_to_stream_completions.ipynb) — 流式输出官方示例
- 💻 [BerriAI/litellm](https://github.com/BerriAI/litellm) — 统一多模型 API 调用，可参考其封装方式
- 📚 [tiktoken](https://github.com/openai/tiktoken) — OpenAI 官方 Token 计数库

### 周末：项目 — CLI 智能助手

**任务**：实现一个支持多轮对话、流式输出、系统 Prompt 可配置的命令行聊天机器人；加入对话历史自动摘要压缩功能

**📚 参考资料**：
- 本周所学全部内容，重点是周五的 API 实战
- 💻 [openai/openai-cookbook](https://github.com/openai/openai-cookbook) — 遇到 API 用法问题先来这里找

**✅ 验收标准**：能解释 attention 计算过程；能独立调用任意大模型 API 并处理流式响应；写出的 Prompt 能稳定输出结构化 JSON

## 第 2 周：Agent 核心概念与手写实现

**目标**：理解 Agent 本质，从零实现 ReAct 循环，不依赖框架

### 周一：Agent 架构范式

**学习内容**：感知-规划-行动循环；ReAct（推理+行动交替）论文精读；Reflexion（自我反思）；Plan-and-Execute；各范式适用场景对比

**📚 学习资料**：
- 📄 ⭐ [ReAct: Synergizing Reasoning and Acting](https://arxiv.org/abs/2210.03629) — **必读精读**，Agent 领域最经典论文
- 📄 [Reflexion: Verbal Reinforcement Learning](https://arxiv.org/abs/2303.11366) — 自我反思机制
- 📄 [Plan-and-Solve Prompting](https://arxiv.org/abs/2305.04091) — 规划先于执行
- ✍️ ⭐ [Lilian Weng · LLM Powered Autonomous Agents](https://lilianweng.github.io/posts/2023-06-23-agent/) — **必读**，Agent 领域最经典综述
- 📖 李博杰《深入理解 AI Agent》[第3-4章](https://bojieli.github.io/ai-agent-book/) — 工具调用 + 推理与规划

### 周二：Function Calling 深度

**学习内容**：工具定义 Schema 规范、参数类型与必填项、工具选择逻辑、并行工具调用、工具执行结果注入对话、工具调用的错误处理与重试

**📚 学习资料**：
- 📚 [OpenAI Function Calling 文档](https://platform.openai.com/docs/guides/function-calling) — 工具调用官方规范
- 📚 [Anthropic Tool Use 文档](https://docs.anthropic.com/en/docs/build-with-claude/tool-use) — 另一种工具调用实现
- 📖 李博杰《深入理解 AI Agent》[第3章](https://bojieli.github.io/ai-agent-book/) — 工具调用原理与工程实现
- 🎓 [吴恩达 Agentic AI · 模块2 Tool Use](https://learn.deeplearning.ai/courses/agentic-ai/information) — 工具使用设计模式

### 周三：记忆系统设计

**学习内容**：短期记忆（滑动窗口/摘要压缩）、长期记忆（向量存储/知识图谱）、记忆的写入与检索策略、Episodic vs Semantic 记忆、记忆遗忘机制

**📚 学习资料**：
- 📖 李博杰《深入理解 AI Agent》[第2章](https://bojieli.github.io/ai-agent-book/) — 上下文工程与记忆
- 💻 [letta-ai/letta](https://github.com/letta-ai/letta)（原 MemGPT）— 分层记忆系统的参考实现，看 README 和架构图
- 📄 [MemGPT: Towards LLMs as Operating Systems](https://arxiv.org/abs/2310.08560) — 记忆换页机制，选读
- ✍️ [Lilian Weng · Agent 博客 · Memory 部分](https://lilianweng.github.io/posts/2023-06-23-agent/) — 记忆系统综述

### 周四：规划与任务分解

**学习内容**：任务拆解策略（自上而下/自下而上）、子目标依赖管理、执行中动态重规划、失败回退与备选路径、最大迭代次数与死循环防护

**📚 学习资料**：
- 📄 [Plan-and-Solve Prompting](https://arxiv.org/abs/2305.04091) — 任务分解策略
- 📄 [Tree of Thoughts](https://arxiv.org/abs/2305.10601) — 搜索式规划
- 🎓 [吴恩达 Agentic AI · 模块3 Planning](https://learn.deeplearning.ai/courses/agentic-ai/information) — 规划设计模式
- 📖 Sam Bhagwat《Principles of Building AI Agents》[Part III](https://mastra.ai/authors/sam-bhagwat) — Workflows & Agents

### 周五：从零写 ReAct Agent

**学习内容**：不使用任何框架，纯 Python + LLM API 实现：Prompt 模板 → 解析 Thought/Action/Action Input → 执行工具 → 观察结果 → 循环直到 Final Answer

**📚 学习资料**：
- 📄 ⭐ [ReAct 论文](https://arxiv.org/abs/2210.03629) — 对照论文的 Prompt 模板和示例
- 💻 [ysymyth/ReAct](https://github.com/ysymyth/ReAct) — ReAct 的简洁实现参考
- 🎓 [吴恩达 Agentic AI · 模块1 Reflection](https://learn.deeplearning.ai/courses/agentic-ai/information) — 反思模式
- 💻 [yoheinakajima/babyagi](https://github.com/yoheinakajima/babyagi) — 极简 Agent（~150行），10分钟读完理解核心循环

### 周末：项目 — 多功能 ReAct Agent

**任务**：为手写 Agent 接入 3+ 工具（搜索、计算器、Python 代码执行）；解决至少一个需要 5 步以上推理的复杂任务；加入最大步数限制和错误恢复

**📚 参考资料**：
- 本周 ReAct 论文和手写实现
- 💻 [huggingface/smolagents](https://github.com/huggingface/smolagents) — 代码简洁的 Agent 库，可参考其工具设计

**✅ 验收标准**：能手写完整 ReAct 循环代码；能设计工具 Schema 并处理调用失败；能解释 Agent 与普通 Chatbot 的本质区别

> ⚠️ **关键提醒**：本周是整个路径的基石。如果手写 ReAct 没搞懂，后面学框架只会是调 API 的熟练工。

## 第 3 周：LangGraph 框架精通

**目标**：掌握最主流的 Agent 框架，能用状态机构建复杂工作流

### 周一：LangChain 基础

**学习内容**：LLM/ChatModel 抽象、PromptTemplate、OutputParser、Chain 组合、Message 类型体系（System/Human/AI/Tool/Function）

**📚 学习资料**：
- 📚 [LangChain Python 文档](https://python.langchain.com/) — 核心概念部分
- 📖 李博杰《深入理解 AI Agent》[第6章](https://bojieli.github.io/ai-agent-book/) — Agent 框架对比
- 💻 [langchain-ai/langchain](https://github.com/langchain-ai/langchain) — 看 examples 目录

### 周二：LangGraph 核心概念

**学习内容**：StateGraph 状态机、State 定义与 reducer、节点(Node)与边(Edge)、条件边(Conditional Branch)、图的编译与执行

**📚 学习资料**：
- 📚 ⭐ [LangGraph 官方文档](https://langchain-ai.github.io/langgraph/) — **核心学习资源**，读 Concepts + Quickstart
- 🎓 [LangChain Academy](https://academy.langchain.com/) — 官方免费课程，交互式练习
- 🎓 [DeepLearning.AI · AI Agents in LangGraph](https://www.deeplearning.ai/short-courses/ai-agents-in-langgraph/) — 吴恩达合作课程

### 周三：LangGraph 高级特性

**学习内容**：检查点(Checkpointer)持久化、人机交互节点(Interrupt)、时间旅行(Travel)回溯、子图(Subgraph)嵌套、流式输出（节点级/Token级）

**📚 学习资料**：
- 📚 [LangGraph 文档 · How-to guides](https://langchain-ai.github.io/langgraph/how-tos/) — 持久化、人机交互、流式等专题
- 💻 [langchain-ai/langgraph · examples/](https://github.com/langchain-ai/langgraph/tree/main/examples) — 官方示例，找 persistence 和 human-in-the-loop 示例

### 周四：用 LangGraph 重构 Agent

**学习内容**：把第 2 周手写的 ReAct Agent 用 LangGraph 重写；对比手写版与框架版的优劣；理解框架帮你处理了哪些边界情况

**📚 学习资料**：
- 💻 [LangGraph examples · react_agent_executor](https://github.com/langchain-ai/langgraph/tree/main/examples) — ReAct 实现参考
- 📚 [LangGraph 文档 · Agentic concepts](https://langchain-ai.github.io/langgraph/concepts/agentic_concepts/) — Agent 概念映射

### 周五：复杂工作流实战

**学习内容**：实现 Plan-and-Execute 模式：规划节点生成任务列表 → 执行节点逐个完成 → 评审节点检查结果 → 不合格则重规划；加入人工确认节点

**📚 学习资料**：
- 💻 [LangGraph examples · plan-and-execute](https://github.com/langchain-ai/langgraph/tree/main/examples) — 官方 Plan-and-Execute 示例
- 🎓 [Hugging Face Agents Course · Unit 3](https://huggingface.co/learn/agents-course/zh-CN/unit0/introduction) — LangGraph 部分
- 📖 Sam Bhagwat《Principles of Building AI Agents》[Part III](https://mastra.ai/authors/sam-bhagwat) — 图工作流设计

### 周末：项目 — 研究助理 Agent

**任务**：用 LangGraph 构建：接收研究问题 → 自动拆解子问题 → 调用搜索工具收集资料 → 整合生成报告 → 支持中途人工干预和修改方向

**📚 参考资料**：
- 🎓 [吴恩达 Agentic AI · 模块5 综合项目](https://learn.deeplearning.ai/courses/agentic-ai/information) — Planner→Researcher→Writer→Editor 架构
- 💻 [LangGraph examples](https://github.com/langchain-ai/langgraph/tree/main/examples) — 找 research-agent 相关示例

**✅ 验收标准**：能独立用 LangGraph 构建多节点、有条件分支、支持持久化的 Agent 工作流；理解 State reducer 的作用；能实现人机交互节点

## 第 4 周：RAG 检索增强生成

**目标**：掌握生产级 RAG 全流程，能搭建高质量知识库问答系统

### 周一：文档处理与切分

**学习内容**：文档解析（PDF/HTML/Markdown）、切分策略（固定长度/语义/递归/结构化）、切分粒度对效果的影响、元数据标注与过滤

**📚 学习资料**：
- 📖 李博杰《深入理解 AI Agent》[第5章](https://bojieli.github.io/ai-agent-book/) — RAG 全链路
- 📚 [LlamaIndex 文档 · Data Connectors](https://docs.llamaindex.ai/) — 文档加载和处理
- ✍️ [Pinecone · Chunking Strategies](https://www.pinecone.io/learn/) — 切分策略最佳实践

### 周二：Embedding 与向量数据库

**学习内容**：Embedding 模型选型与维度、向量数据库对比（Milvus/Qdrant/Chroma/pgvector）、索引类型（HNSW/IVF）、相似度计算（余弦/点积）

**📚 学习资料**：
- ✍️ [Pinecone Learning Center](https://www.pinecone.io/learn/) — 向量检索系统学习
- 📚 [Milvus 文档](https://milvus.io/docs) / [Qdrant 文档](https://qdrant.tech/documentation/) — 选一个深入
- 📚 [MTEB Leaderboard](https://huggingface.co/spaces/mteb/leaderboard) — Embedding 模型对比基准
- 🎓 [Hugging Face Agents Course · Unit 4](https://huggingface.co/learn/agents-course/zh-CN/unit0/introduction) — RAG 部分

### 周三：检索策略优化

**学习内容**：混合检索（向量+关键词 BM25）、查询改写（HyDE/多查询/步骤回退）、父文档检索(Parent Document)、上下文压缩(Contextual Compression)

**📚 学习资料**：
- 📄 [HyDE: Precise Zero-Shot Dense Retrieval](https://arxiv.org/abs/2212.10496) — 查询改写经典方法
- 📄 ⭐ [Lost in the Middle](https://arxiv.org/abs/2307.03172) — **必读**，长上下文位置对效果的影响
- 🎓 [DeepLearning.AI · Advanced Retrieval for AI](https://www.deeplearning.ai/short-courses/advanced-retrieval-for-ai-with-chroma/) — 高级检索策略
- 📚 [LlamaIndex 文档 · Retrieval](https://docs.llamaindex.ai/) — 各种检索器实现

### 周四：重排序与生成优化

**学习内容**：Rerank 模型（Cohere/bge-reranker）、检索结果去重与多样性、Prompt 中上下文组织、引用溯源、不知道就拒答的策略

**📚 学习资料**：
- 📚 [Cohere Rerank 文档](https://docs.cohere.com/docs/reranking) — 重排序原理和使用
- 💻 [FlagOpen/FlagEmbedding](https://github.com/FlagOpen/FlagEmbedding) — bge-reranker 开源实现
- 📚 [LlamaIndex · Postprocessor](https://docs.llamaindex.ai/) — 重排序和上下文压缩

### 周五：RAG 评估方法

**学习内容**：检索质量评估（Recall@K/MRR/NDCG）、生成质量评估（忠实度/相关性）、RAGAS 框架、构建评估集、常见失败模式分析

**📚 学习资料**：
- 📄 [RAGAS: Automated Evaluation of RAG](https://arxiv.org/abs/2309.15217) — RAG 评估框架论文
- 💻 [explodinggradients/ragas](https://github.com/explodinggradients/ragas) — RAGAS 官方仓库和文档
- 🎓 [DeepLearning.AI · Building and Evaluating Advanced RAG](https://www.deeplearning.ai/short-courses/building-evaluating-advanced-rag/) — 评估实战
- ✍️ [LangChain · RAG from Scratch (YouTube)](https://www.youtube.com/playlist?list=PLfaIDFEXuae2LXbO1_PKyVJiQ23ZztA0x) — 从零实现 RAG 各环节

### 周末：项目 — 知识库问答系统

**任务**：选取一个领域文档集，搭建完整 RAG 流水线：切分→向量化→混合检索→重排序→生成→引用标注；对比不同策略的效果差异

**📚 参考资料**：
- 本周所有 RAG 资料
- 💻 [run-llama/llama_index](https://github.com/run-llama/llama_index) — 参考其 RAG 流水线实现

**✅ 验收标准**：能搭建完整 RAG 流水线并解释每个环节的作用；能通过评估指标定位 RAG 效果差的原因（检索问题 vs 生成问题）

## 第 5 周：多 Agent 协作系统

**目标**：掌握多 Agent 协作模式，能构建多角色协同系统

**📚 学习资料**：
- 📄 [AutoGen: Multi-Agent Conversation](https://arxiv.org/abs/2308.08155) — 多 Agent 对话框架论文
- 📄 [MetaGPT: Meta Programming for Multi-Agent](https://arxiv.org/abs/2308.00352) — 角色化协作
- 📖 李博杰《深入理解 AI Agent》[第10章](https://bojieli.github.io/ai-agent-book/) — 多 Agent 协作
- 🎓 [吴恩达 Agentic AI · 模块4 Multi-Agent](https://learn.deeplearning.ai/courses/agentic-ai/information) — 多 Agent 设计模式

### 周二：Agent 角色与分工设计

**学习内容**：角色定义（专业能力/工具权限/输出格式）、任务分配策略、结果聚合与冲突解决、角色间信息传递协议

**📚 学习资料**：
- 📄 [MetaGPT 论文](https://arxiv.org/abs/2308.00352) — 软件公司角色分工
- 📚 [CrewAI 文档](https://docs.crewai.com/) — 角色化 Agent 设计参考
- 📄 [CAMEL: Communicative Agents](https://arxiv.org/abs/2303.17760) — 角色扮演对话范式

### 周三：AutoGen 与 CrewAI

**📚 学习资料**：
