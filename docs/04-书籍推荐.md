# 04 - 书籍推荐

> 中英文书籍、开源书、专项主题书，按推荐程度排序。

## 选书原则

1. **出版时间**：优先 2025 年及以后出版的书，Agent 领域迭代快，2024 年及以前的内容可能已过时
2. **不绑定框架**：优先讲设计原理的书，而不是某个框架的使用手册
3. **有代码示例**：Agent 是工程学科，有可运行代码的书比纯理论更有价值
4. **不要同时读多本**：选 1-2 本主线读完，其余按需查阅章节

## ⭐ 首推（免费开源）

### 深入理解 AI Agent：设计原理与工程实践
- **作者**：李博杰（bojieli），前华为天才少年、Pine AI 首席科学家
- **GitHub**：https://github.com/bojieli/ai-agent-book
- **在线阅读**：https://bojieli.github.io/ai-agent-book/
- **作者博客**：https://01.me/
- **出版**：2026.07 开源，Apache 2.0 协议
- **规模**：10 章，95 个配套实验，35k+ GitHub Star
- **语言**：中文原版，多语言社区翻译
- **核心公式**：`Agent = LLM + 上下文 + 工具`

**内容结构**：
1. 第1章 Agent 基础知识：从模型到智能体的范式转变
2. 第2章 上下文工程：提示词、记忆与上下文窗口管理
3. 第3章 工具调用：Function Calling 原理与工程实现
4. 第4章 推理与规划：CoT、ReAct、Plan-and-Execute
5. 第5章 检索增强生成（RAG）：从检索到生成的全链路
6. 第6章 Agent 框架：LangGraph、AutoGen 等架构对比
7. 第7章 模型后训练：SFT、RLHF 与 Agent 专项训练（可选，需 GPU）
8. 第8章 评估与调试：Agent 质量度量与问题定位
9. 第9章 多模态 Agent：语音、视觉、Computer Use
10. 第10章 多 Agent 协作：群体智能与 Agent 社会

**推荐理由**：
- 中文原创，无语言障碍，术语翻译准确
- 完全开源免费，PDF/EPUB/在线阅读/配套代码全部提供
- 紧跟 2026 年前沿，覆盖 MCP、Computer Use、多模态等最新内容
- 理论+实验结合，95 个可运行实验边读边练
- 不绑定框架，从第一性原理讲设计

**使用建议**：作为主线教材贯穿全程。第7章（模型后训练）对应用开发方向可跳过。

### Principles of Building AI Agents（第2版）
- **作者**：Sam Bhagwat（Mastra CEO）
- **作者页面**：https://mastra.ai/authors/sam-bhagwat
- **GitHub**：https://github.com/mastra-ai/mastra（书在仓库中）
- **出版**：2025.05 第2版，免费电子书
- **语言**：英文

**内容结构**：
- Part I：Prompting LLM——提示工程与结构化输出
- Part II：Tools & MCP——工具设计与模型上下文协议
- Part III：Workflows & Agents——图工作流与自主 Agent
- Part IV：RAG & Memory——检索增强与记忆系统
- Part V：Multi-Agent——多 Agent 系统设计
- Part VI：Evals & Deployment——评估与生产部署

**推荐理由**：
- 完全免费，工程实践导向
- 被称为「旧金山最受欢迎的 Agent 书」
- 强项是生产环境经验和「什么时候该用 Agent、什么时候该用确定性工作流」的判断框架
- Part VI（评估与部署）质量很高

**注意**：书是 TypeScript/JavaScript 技术栈，但设计原则通用。

## 英文系统教材

### AI Agents in Action (2nd Edition)
- **作者**：Micheal Lanham
- **出版社**：Manning
- **链接**：https://www.manning.com/books/ai-agents-in-action-second-edition
- **出版**：2026.06，392 页

**内容亮点**：
- 覆盖 LLM 工作流、MCP 协议、A2A（Agent-to-Agent）等 2026 年最新标准
- 从本地 Agent 到生产系统全流程
- 大量可运行代码示例
- 主题包括：本地开源模型、MCP 网关、多 Agent 时机、推理失败原因、记忆与检索、并发与队列

**推荐理由**：Manning 出品品质保证，内容最新，覆盖 MCP/A2A 等新标准。

- 作者有丰富的生产级多 Agent 系统经验（网络安全方向）
- 覆盖单 Agent 和多 Agent 系统的设计与实现

## 避坑提醒

1. **低代码平台书慎选**：基于 Coze/Dify 等平台的书适合快速出原型，但平台会变，原理不会变
2. **注意出版时间**：2024 年及以前的 Agent 书可能缺少 MCP、A2A、Computer Use 等内容
3. **不要囤书**：选 1-2 本主线读完，其余按需查阅，同时读多本效率低
4. **优先有代码的**：Agent 是工程学科，纯理论书价值有限
