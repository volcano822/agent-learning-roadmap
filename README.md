## ⚡ 快速开始

1. **先读** [docs/01-学习路径.md](docs/01-学习路径.md)，了解整体节奏和每周目标
2. **选一本主线教材**：推荐李博杰《深入理解 AI Agent》（免费开源）
3. **按周推进**：工作日学概念+小练习，周末集中做项目
4. **遇到问题时**：查阅对应主题的资源文档（论文/课程/书籍/开源项目）

## 💡 学习建议

### 时间分配
- 工作日：每天 2-3 小时，学概念 + 写小练习
- 周末：每天至少 4 小时，集中做项目
- 项目是主线，所有概念学习都服务于当周的项目产出

### 核心原则
1. **不要跳过基础直接学框架** — 第2周手写 ReAct Agent 是整个路径的基石
2. **框架选一个深钻** — 推荐 LangGraph，其余了解设计思想即可
3. **评估比优化更重要** — 没有量化指标，所有"优化"都是玄学
4. **尽早做完整项目** — 第8周的实战可以和第4-5周并行
5. **关注前沿** — Agent 领域迭代快，定期看 arXiv 和 GitHub Trending

### 资源优先级
- **首推**：李博杰《深入理解 AI Agent》— 免费、中文、最新、有实验
- **课程**：吴恩达 Agentic AI + Hugging Face Agents Course
- **工程参考**：Sam Bhagwat《Principles of Building AI Agents》
- **实战参考**：OpenDevin、SWE-agent 等开源项目源码

## 📌 核心公式

```
Agent = LLM + 上下文 + 工具
```

所有 Agent 设计都围绕这三个要素展开：
- **LLM**：推理引擎，负责理解和决策
- **上下文**：记忆系统 + Prompt 工程，决定 Agent 知道什么
- **工具**：Function Calling + MCP，决定 Agent 能做什么
